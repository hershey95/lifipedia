# 신고는 무작위로 뽑힌 배심원이 판정한다

신고 판정을 운영자가 하면 "운영자 큐레이션 없음" 원칙과 부딪친다. 또 기여에 돈이 걸리면 신고가 경쟁자를 공격하는 수단이 된다. 그래서 신고가 기준을 넘으면, 자격 있는 사용자 가운데 기록된 시드로 무작위 추첨한 배심원 5명이 서로의 표를 보지 않고 판정한다. 신고자, 신고 대상, 같은 소분류의 분배 경쟁자는 배심원에서 뺀다. 배심원 정족수가 안 차면 운영자에게 넘기고(2026-11-26), 표가 3분의 2에 못 미치거나 운영자도 기한을 넘기면 구제한다. 게시판 글과 댓글은 판정 동안 블라인드하지만, 문서는 블라인드하지 않고 문제 리비전만 되돌린다. 문서를 가리면 순위를 공격하는 수단이 되기 때문이다. 운영자는 법적 임시조치를 하고, 사건의 적격 배심원이 3명 미만이거나 배심 정족수가 안 찼을 때에만 대신 판정한다(2026-11-26). 적격자가 모이면 규칙에 따라 자동으로 배심원에게 넘어간다. 운영자의 조치와 판정은 전부 공개 기록에 남긴다. ref-security Q7 과 W45-4 의 미결정을 이 결정으로 닫는다. 상세: `docs/design/plan-reward-jury.md` 6절.
