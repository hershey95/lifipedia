# 통합 로드맵 W43~W46 (2026-10-12 작성, Claude)
근거 문서: `ref-backend.md`(백엔드), `ref-frontend.md`(프론트), `ref-design-system.md`(디자인), `ref-security.md`(보안). 각 문서는 Opus 가 레퍼런스(Wikipedia·나무위키·Reddit·디시)를 우리 철학(운영자 큐레이션 없음, 신뢰도는 기여에서만, 재현 가능한 랭킹)에 맞춰 채택/변형/비채택으로 정리한 것이다. 이 문서는 네 문서를 충돌 없이 한 순서로 합친다.

## 충돌 조정 (Claude 판정)
| 쟁점 | 문서별 입장 | 결정 |
|---|---|---|
| `ink` 색 문제 | 프론트: `ink` 값을 `#e2e8f0` 로 한 줄 수정. 디자인: `ink` 를 `fg` CSS 변수로 재정의하는 브리지 | **디자인안** (CSS 변수 브리지). 둘 다 "먼저 보이게 하고, 나중에 기계 치환해 `ink` 삭제"로 같은 방향 |
| 편집 요청 큐 | 백엔드: W44 `EditRequest`(202). 프론트: 충돌 해결 UX 때문에 보류 | **W45 이후로 보류**. W44 는 보호 수준을 계산하되 권한 부족 편집은 403 + 안내로 시작 |
| 개념글 기준 | 백엔드: 가중 추천 8·추천자 5·Wilson 0.6·7일. 프론트: `upCount ≥ 5` | **백엔드 규칙**(서버 계산). 프론트는 결과만 표시 |
| 갤러리 라우트 | 프론트: `/gallery/[slug]` 를 `/theme/[slug]` 로 통합 | 채택, 영구 리다이렉트 |
| 기여 산정 | 백엔드 `ContributionEvent` + 보안 "신뢰도 파밍" 지적 | **같은 작업**. W43 첫 항목 |
| 출처·각주 | 백엔드 `Item.sources`, 프론트 각주 렌더 | W46 에 묶음. 콘텐츠의 `facts:[{sentence,source,quote}]` 구조 전환의 기반이 된다 |

## 이미 끝난 것 (2026-10-12 새벽)
`/me` 마이페이지, `PATCH /api/me`, 검색 `mode: 'insensitive'` 제거(검색 500 해소), 외부 링크 http(s) 스킴 제한, `.dockerignore` 에 DB 제외, 빌드 lint 오류 정리.
