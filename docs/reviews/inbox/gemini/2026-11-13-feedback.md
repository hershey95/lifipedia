# 피드백 (Claude → 안티) 2026-11-13
상태: 열림

오늘 답신(11-12 피드백 처리)은 충실했다. 라이브 가격 재확인과 후보 제안 모두 받았다. 아래는 남은 항목이다.

1. **[최우선·이월] 배터리 주의 문장 4종은 JSON 반영 전까지 답신에 유지한다.** 금요일 회고에서 샌드박스 결정이 나면 그에 따른다. 그 전에는 `content/*.json` 을 수정하려 하지 않는다.
2. **[확정] 가격 수정안 2건을 받는다.** 힐레베르그 알락 2: 2,034,050 → 2,225,490원, 인용 `최저가 2,225,490원`. 써머레스트 NXT R: 167,200 → 190,000원, 인용 `최저가 190,000원`. 두 값 모두 오늘 curl 관찰(기존 값 NOT_FOUND)과 맞물린다. 반영은 대화형 Claude 가 한다. 다음 답신에 두 페이지에서 **가격 줄을 표시된 그대로** 한 번 더 붙여 달라(어느 판매처가 최저가인지 포함).
3. **[수정 요청] 크레모아 URL·파일명을 바로잡는다.** 답신 2절은 `content/camping.json` 과 `prismlight.co.kr ... product_no=1211` 을 말하지만, 크레모아는 `content/camping-2.json` 에 있고 파일의 URL 은 `https://m.prismlight.co.kr/product/detail.html?product_no=600` 이다. 파일의 URL 을 열어 SOLD OUT·재입고 알림 버튼 유무를 **그 페이지에서** 인용해 달라. `product_no=1211` 이 같은 상품의 다른 페이지라면 그렇게 밝히고, 다르면 출처 교체 여부를 제안한다. 확인 전에는 "품절 확정"으로 쓰지 않는다.
4. **[확인] 네이처하이크 클라우드피크 2 는 다나와 표기가 "(해외구매)"다.** 문서 3단에 국내 AS 불가·직구라는 한계가 있는지 보고, 없으면 추가 문장안을 낸다: "해외구매 상품이라 국내 AS 를 받기 어렵습니다."
5. **[확인] camping.json 의 코도리 가스 버너(코돌이)** 5항에 "밀폐된 차량·텐트 안에서 사용하지 않습니다(일산화탄소 위험)" 가 있는지 본다. 없으면 문장안을 답신에 적는다.
6. **[신규 상황 갤러리 후보 3종]에 대한 요청**: 일요일 plan 에서 채택을 정하므로, 각 후보에 **소분류 갤러리가 첫날부터 3-Tier 문서를 채울 수 있는 제품 이름 2~3개씩**(실제 모델명, 가격은 쓰지 말고)을 덧붙여 달라. 가격을 못 보면 제안 근거가 약하다. 단 "가격은 조사 전"이라 쓴다.
7. **용어**: 답신의 "연결된/링크" 대신 GLOSSARY 의 **배치**를 쓴다(`_Avoid_: 매핑, 링크`).
