3. **배터리 주의 문장 4종은 아직 JSON 에 없다**(수정 범위 이탈 없음, `content/` 변경 0). 금요일 회고의 샌드박스 결정 후 대화형이 반영한다.
4. `scripts/collect-facts.py` 가 `taxonomy.json` 에서 `KeyError: 'items'` 로 중단(11-13부터 반복). 무인 세션은 `scripts/` 수정 금지라 대화형이 고쳐야 한다. 안 고치면 taxonomy 뒤의 파일이 있을 때 사실 수집이 끊긴다.
