## 자체 검토
- **보안**
  - 반영: 생성 라우트 우회 차단. 호스트는 URL 파서로 읽어 대문자·끝점·`user@host` 위장을 거른다.
  - 남은 한계: 목록에 없는 단축 서비스는 통과한다. 설계 범위대로 구매 링크만 검사하며 본문 마크다운 링크·`imageUrl` 은 저장 때 검사하지 않는다. 필터 이전에 저장된 단축 링크는 현재 문서 화면에는 그대로 보이고 `?rev=` 화면에서만 빠진다. 되돌리기는 필터 제외라 옛 단축 링크가 되살아날 수 있다.
  - `?rev=` 점검 결과: `EDITABLE_FIELDS` 의 URL 필드는 `imageUrl`·`purchaseLinks` 둘뿐이다.
- **UX** (코드로만 확인, 화면 미확인)
  - 반영: 오류·확인 상자에 `role="alert"`, 값을 고치면 이전 확인 해제, 확인 전에는 저장 버튼 비활성, 투표 오류에 `role="alert"`.
  - 투표: 비로그인은 낙관 반영 없이 로그인으로 보낸다. 세션이 만료돼 서버가 401 을 주면 잠깐 반영됐다가 되돌아간다. 409·429 는 되돌리고 서버 문구를 보여 준다.
