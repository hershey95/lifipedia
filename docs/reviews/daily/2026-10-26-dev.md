- **`npm run build` 가 끝까지 통과하지 못했다.** 컴파일·린트·타입 단계는 통과(`✓ Compiled successfully`), 정적 페이지 생성 단계에서 `The table main.Theme does not exist` (P2021)로 실패. `prisma/dev.db` 가 비어 있거나 구 스키마다. DB 수정이 금지라 `db push` 를 못 했다(임시 DB 로 시도했으나 그 명령도 권한에서 거부됨). 코드 변경과 무관한 환경 문제로 보지만, 변경 전 상태로 빌드해 대조하지는 못했다.
