## 사용자 결정 필요 (기본값으로 진행 중. 같은 질문을 3일 넘게 반복하지 않는다)
1. **게이트 G (실행, 월 오전)**: `cp prisma/dev.db prisma/dev.db.bak` → `npm run db:push` → `npm run build`. 이어서 `scripts/` 3건(collect-facts 의 `items` 건너뛰기, 시드 import 래퍼, 재배치 래퍼), `content/taxonomy.json` 가져오기, 무인 Bash 허용 상태 한 줄 기록. P1 이 끝나면 `db:push` 를 한 번 더 한다.
2. 인기의 가중투표 해석: 기본값은 **참여량(UP·DOWN 모두)** 유지이고, 공개 설명에 그대로 적는다. 순추천으로 바꾸려면 알려 달라.
3. 도움됨을 기여로 적립할지: 기본값은 **적립 안 함**(`helpfulAt` 만 기록)이다. 신뢰도 산식 변경이고, 부계정으로 신뢰도를 쌓는 데 쓰일 위험이 있다.
4. 신고 처리 검토자(W45-4): 게시판을 열면 스팸을 지울 수단이 사람의 DB 수정뿐이다. 우선순위를 올릴지 정해 달라.
5. `vid` HMAC 서명(환경변수 신설): 기본값은 서명 없음이고, https 요청에만 `Secure` 를 붙인다.
- 종결: "분류 인기에 조회수를 넣을지"(11-14 결정 3). ADR 0001 본문이 인기의 정렬 신호로 허용한다(설계서 6.2).
