## 한 줄 결론
단계 순서(신고 → 모의 정산 → 실제 지급)는 읽히지만, **이대로는 1단계도 구현 지시서로 쓸 수 없다.** 게시판 개념글 점수의 전제가 코드에 없고, 신고→사건→판정의 상태 모델과 되돌리기 호출 방식이 비어 있다.
