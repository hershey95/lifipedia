# Stage 8: 중간 Zoom Out 보고 (1-278행)

검토자: egm-zoom-out (새 컨텍스트). 읽은 것: 설계서 전문, Stage 5·6·7 보고서, 기준 문서 4종. 코드는 `httpUrl` 사용처와 `?rev=` 스냅샷 처리만 확인했다. 설계서는 수정하지 않았으므로 "지금 문서가 그대로 서는가"를 기준으로 앞 단계 지적을 다시 걸렀다.

판정: **조건부 통과, Blocker 없음.** 설계 방향(스키마 없이 계산, 기존 함수 재사용, 거름망 세 가지, ADR 0001·0002 준수)은 서 있다. 문제는 6절(원안)과 10절(수정분)이 겹친 문서 상태다.

## 남는 지적

### Major
- **M1 (154, 158-172 대 222, 261행)** 완료된 W1·W2 본문이 R-1 과 충돌한 채 남았다. 누락 필드 폴백(163 빈 값 vs 261 `name`·`tier` 현재 값), 역링크 필드(169 한 개 vs 261 세 필드 OR), 리졸버 필터(168 `isRemoved` vs 261 `+ACTIVE`). 154행 "W1~W5 설계는 그대로 유효"가 10.1 #3·10.4 와 어긋난다. 최소 수정: 154행을 "W1·W2 완료(11-19), 변경은 10.4 R-1 우선"으로 고치고 158-172행에 같은 표시를 단다. 본문을 다시 쓸 필요는 없다.
- **M2 (174-179행)** W3 의 실제 위험은 전 문서 스캔이다. 176행 "만들어 주세요"·"나가는 링크 없음"이 전 문서에 `extractWikiLinks` 를 돌리는데 169행의 "1만 개" 한계는 역링크 LIKE 에만 붙어 있다. 176행에 규모 가정과 `ponytail:` 한계를 적는다. Orphaned 의 O(N²) 는 176행 목록에 Orphaned 가 없어 지금은 해당 없다(넣을 때만 "한 번 훑어 정방향 맵을 뒤집는다"). 목록 6종을 2종으로 줄이자는 Stage 5 제안은 사용자 지시와 3.1절을 되돌리므로 권하지 않는다.

### Minor
- m1 (43, 59, 176행) Orphaned·동명 문서 링크가 큐 ③ 인데 176행 목록에 없고, 40행 "필수 절들" 대 175행 `## 출처` 하나. 59행을 W50+ 로 내리면 `[[이름@소분류]]` 문법 제안(IC-A3)은 필요 없다. 그 문법은 137행 틀 거부와 같은 이유로 권하지 않는다. 일반 마크다운 링크로 특정 문서를 가리킬 수 있는지는 코드에서 확인하지 못했고 그 확인이 먼저다.
- m2 (86, 111, 120, 186-187행) 편집 필터 용어를 block·confirm·hint 로 통일한다. 187행에 hint 를 보일 경로가 없으니 W49 에서 빼거나 클라이언트 문구로만 둔다. `confirmed:true` 는 마찰 장치이지 방어선이 아니므로 IC-B4 의 우회 지적은 거짓 경보다.
- m3 (3, 154-156, 244행) 지난 일요일 지시문과 낡은 문장(156행 "새 컬럼은 S 하나뿐", "하루 2개, 최대 8칸")을 삭제하거나 "11-22 이전 원안"으로 표시한다.
- m4 (17-31행) 2절 현황표에 "11-18 기준, W1·W2 는 11-19 완료"를 쓴다.
- m5 (6, 146-151행) 집계 불일치는 147행이 스스로 인정하고 구현에 영향이 없다. Stage 6 의 Blocker 1 을 Nit 로 낮춘다. 6행 "하나씩 판정" 표현만 약하게 고친다.
- m6 (9, 200-209행) 7절 머리말이 "스키마 필요"인데 208행(비교·미리보기·충돌 해결)과 205행(감사 표시, `Notification` 재사용)은 스키마 불필요다. 머리말에 "G 선행 필요 여부" 열을 더한다.
- m7 (229, 215행) **`?rev=` 스냅샷 URL 검증은 이미 렌더 시점에 있다.** `src/app/theme/[slug]/item/[itemSlug]/page.tsx:79-81` 이 스냅샷의 `imageUrl`·`purchaseLinks` 를 `httpUrl.safeParse` 로 거른다. `revert/route.ts:70` 도 같은 검사를 한다. 따라서 Stage 5 의 "W4 까지 4일간 검증 공백"(IC-B5)은 대부분 거짓 경보이고 `url-policy.ts` 신설은 권하지 않는다. 남는 일: 229행 문구를 "렌더 시 `httpUrl` 은 이미 적용, W4 는 차단 도메인만 추가"로 정정하고, R-1 테스트에 "스냅샷의 `javascript:` URL 이 렌더에서 제외된다"를 한 줄 넣는다.
- m8 (244-254행) 임시 DB 로 `db push` 후 build 하는 방법(IC-B1)은 위험이 낮으나 Bash 허용이 필요해 G-대화형 영역이다. 설계서에는 G-대화형 후보로 한 줄만 둔다.
