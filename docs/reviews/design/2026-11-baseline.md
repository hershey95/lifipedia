# 디자인 기준선 감사 (Hallmark audit, 2026-11-10)
- 도구: Hallmark v2.0.0 `sloplint --url ... --scope app --render` (Chrome 렌더, 1280/1440/1920/375/320 폭). 대상: `/`, `/theme/캠핑차박-갤러리?tab=rank`, 그 문서 페이지, `/recent`. 읽기 전용, 파일 수정 없음.
- 범위의 한계: 소스 없이 URL 로 돌려 `file:line` 은 없다. 판정형 게이트(gates.md §5)는 걷지 않았다(린트 수준 감사).

## 린트가 못 잡은, 사람이 본 것(참고, 규칙 위반으로 단정하지 않음)
Hallmark 의 바닥 규칙은 마케팅 페이지 기준이라 앱 화면에는 그대로 적용하지 않는다(`docs/agents/design-team.md`). 다만 같은 관점에서 눈에 띈 점:
- 이모지를 아이콘처럼 사용(사이드바 🏛 👥 ⚡ 🚀 …). 접근성·일관성 면에서 SVG 아이콘 세트로 교체 후보.
- 가운뎃점으로 이은 메타 문자열(`73,990원 · 리비전 1 · 작성 …`, 최근 변경 행). 정보 위계가 평평하다. 구분이 필요한 곳만 라벨/값 쌍으로.
- 문서 페이지 "광고 영역" 자리표시가 그대로 노출. 광고 붙이기 전까지 숨김.
- 작성자 "탈퇴한 사용자"로 일괄 표시(가져온 문서의 작성자 없음) → "위키 가져오기" 표기가 낫다.

## 조치 큐 (구현 세션이 집는다, 작은 순서)
1. 사이드바 허브 버튼 높이·영역 (REFLEX 39b), 2. 홈 칩 줄바꿈 (49b), 3. "광고 영역" 숨김, 4. 가져온 문서 작성자 표기. 이모지 아이콘·메타 문자열은 T2·T3 화면 개편 때 같이 정리한다.
