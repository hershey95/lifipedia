## 2. 계획과 달라진 판단과 이유
1. **큐가 하루씩 앞당겨졌다.** 화요일에 C 까지 끝나 W4·`useOptimistic` 이 수요일, W5 가 목요일이 됐다. 첫 `[ ]` 규칙대로다.
2. **W4 가 리서치보다 먼저 구현됐다.** 10.1 #7 은 11/25 위키 리서치를 쓰려고 W4 를 목요일로 옮겼다. 실제로 W4 는 수요일 11:00 에 집혔고 리서치는 같은 날 15:00 에 돌았다. 설계서는 산출물 경로도 `docs/reviews/research/` 로 적었지만 스크립트는 `docs/research/` 에 쓴다. W4 는 설계 기본값으로 나갔다. 리서치는 임계값·차단 목록은 유지하라고 했고, 본문 링크 미검사와 각주 렌더 결함을 새로 지적했다.
3. **W4 설계 밖 보완.** 문서 생성 라우트에도 block 적용(새 문서 우회 차단), 가격 삭제도 confirm. 타당하다.
4. **임시 저장본에 기준 리비전 저장(58bf39f).** 처음 구현은 409 뒤 새로고침하면 작성 내용을 잃었다. 자체 검토가 잡았다.
5. **새 사용자 지시(기여 보상·배심원)가 이번에는 큐를 밀지 않았다.** 11-25~26 에 설계만 하고 구현은 W50 E 로 넣었다. W47·W49 에서 반복된 패턴이 이번에는 없었다.
6. **분류 갤러리 순위 탭을 티어별 1위만으로(6e4804d).** 안티가 전달한 지시를 보류했다가 사용자 확인 뒤 반영했다. 전달된 "오너 결정"을 확인하고 반영하는 절차가 작동했다.
